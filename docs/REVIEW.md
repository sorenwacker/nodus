### Recurring themes

1. **Silent failure instead of a reported one.** An outage read as an empty result, an error row that can never render, a logger level that can never emit, a registered command that reports success without doing anything.
2. **Code that nothing reaches.** 27 of 71 agent tools exposed to no surface, four components never mounted, a whole composable unreachable, settings written to storage nothing reads.
3. **The same rule implemented several times.** The frontmatter block parsed by three different expressions that disagree on CRLF, colour maps forked between components, entity metadata duplicated across five files.
4. **State captured once and assumed live.** A selection array captured at construction, computed values over non-reactive storage reads, a timer that outlives the node it was armed for.
5. **Rules without gates.** The 1000-line limit has no enforcement, and six files have drifted past it.
